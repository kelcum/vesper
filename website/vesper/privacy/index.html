Privacy

Vesper doesn't collect your data.

Last updated 13 October 2026. This covers the Vesper app for Windows and macOS and this website.

What Vesper sends

  • Roblox's public client settings service (clientsettingscdn.roblox.com): to see the latest Roblox version and the Fast Flag values Roblox publishes. No account, cookie or identifier is sent.
  • xan.gripe: to check for Vesper updates, if you leave automatic checks on, and to download an update when you choose to install it. Like any web request, this reveals your IP address to the host, GitHub Pages.
  • Discord, on your PC: only if you turn on Rich Presence. Vesper talks to the Discord app running locally, which shows “Using Vesper”, a button to this site, whether Roblox is running and, if you choose, your profile's name.

What Vesper never does

  • Collect telemetry, analytics or crash reports.
  • Read Roblox cookies, authentication tickets, passwords or tokens.
  • Read your Roblox account, friends, inventory or chat.
  • Inject code into Roblox or interfere with its anti-cheat.
  • Install anything else or run hidden processes.

What stays on your PC

Settings, profiles, backups and logs are stored in %APPDATA%\Vesper and %LOCALAPPDATA%\gripe.xan.vesper on Windows (or next to Vesper.exe in portable mode), and in ~/Library/Application Support/Vesper, ~/Library/Logs/Vesper and ~/Library/Caches/gripe.xan.vesper on macOS. Pictures you pick for the emote wheel or cursor are copied there too, and only into Roblox's own files on your computer. Logs and the diagnostics you can copy remove your Windows or macOS user name and anything that looks like a secret. Uninstalling on Windows with “Delete the application data” ticked removes these folders; on a Mac, delete them yourself.

This website

This page uses no cookies, analytics or third-party scripts. Fonts and images are served from this site.

Changes and contact

If this changes, for example if an optional feature ever needs to send data, it will be off by default, explained in the app, and listed here first. Questions or concerns: use the contact link on xan.gripe.
