Privacy

Vesper doesn't collect your data.

Last updated 17 October 2026. This covers the Vesper app for Windows and macOS and this website.

What Vesper sends

  • Roblox's public client settings service (clientsettingscdn.roblox.com): to see the latest Roblox version and the Fast Flag values Roblox publishes. No account, cookie or identifier is sent.
  • xan.gripe: to check for Vesper updates, if you leave automatic checks on, and to download an update when you choose to install it. Like any web request, this reveals your IP address to the host, GitHub Pages.
  • Discord, on your computer: only if you turn on Rich Presence. Vesper talks to the Discord app running locally, which shows “Using Vesper”, a button to this site and, unless you turn them off in Settings → Discord, whether Roblox is running, your profile's name and the game you're playing (its name, creator, icon and your time in it). A “Join server” button (public servers only) and a “Roblox profile” button appear only if you turn them on.
  • Roblox's public game APIs (games.roblox.com, thumbnails.roblox.com, users.roblox.com, apis.roblox.com): while you play, to show the game's name and icon and, for the profile button, your user name. Only the game's or user's public ID is sent.
  • Roblox's public download (setup.rbxcdn.com), on a Mac only, when you use Customize: if one of the Roblox files Vesper customises isn't Roblox's own (another tool changed it), Vesper reads Roblox's own copy of just that file from Roblox's download of the Mac app. No account, cookie or identifier is sent.
  • RoValra's public server database (apis.rovalra.com), only for features you turn on. With server picking (Settings → Servers), the game's place ID, to find its servers by city. With server locations (Recent games), the address of the Roblox server you're in, to find its city. Nothing about you is sent, but like any web request it reveals your IP address to RoValra.
  • Amazon Web Services, only when you test your ping or use server picking: Vesper opens and immediately closes a connection to a public endpoint in each of 27 cities (dynamodb.*.amazonaws.com) to time the round trip. No data is sent over these connections.

What Vesper never does

  • Collect telemetry, analytics or crash reports.
  • Read Roblox cookies, authentication tickets, passwords or tokens.
  • Read your friends, chat, avatar or inventory.
  • Inject code into Roblox or interfere with its anti-cheat.
  • Install anything else or run hidden processes.

What stays on your computer

Settings, profiles, backups and logs are stored in %APPDATA%\Vesper and %LOCALAPPDATA%\gripe.xan.vesper on Windows (or next to Vesper.exe in portable mode), and in ~/Library/Application Support/Vesper, ~/Library/Logs/Vesper and ~/Library/Caches/gripe.xan.vesper on macOS. Pictures you pick for the emote wheel or cursor are copied there too, and only into Roblox's own files on your computer. Logs and the diagnostics you can copy remove your Windows or macOS user name and anything that looks like a secret. The Recent games list (games, servers, their cities and times) stays in the same folder; turn it off or clear it on its page. Uninstalling on Windows with “Delete the application data” ticked removes these folders; on a Mac, delete them yourself.

This website

This page uses no cookies, analytics or third-party scripts. Fonts and images are served from this site.

Changes and contact

If this changes, for example if an optional feature ever needs to send data, it will be off by default, explained in the app, and listed here first. Questions or concerns: use the contact link on xan.gripe/k3.
